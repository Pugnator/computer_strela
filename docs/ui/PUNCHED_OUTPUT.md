# Выдача результатов и изображение перфокарт

«Пуск» по умолчанию выполняет программу до машинного останова. Флажок «Ограничить время счёта» включает заданный предел для следующего пуска. Замедление показа по умолчанию — 50 мс на команду; оно не изменяет машинное время. Без замедления счёт выполняется порциями по 100 000 мкс с возвратом управления браузеру, чтобы оставался доступен «Останов».

Окно выдачи открывается после нормального останова, если ядро выдало хотя бы одно слово. Повторный просмотр доступен кнопкой «Выданные перфокарты». Esc и «Закрыть» закрывают окно и возвращают фокус на эту кнопку. Колода перелистывается кнопками и стрелками влево/вправо.

Данные берутся из strela_machine_read_punched, а не из предполагаемых ячеек памяти. Веб- и машинная версии предоставляют одинаковое постраничное чтение колоды; один ответ содержит не более 128 слов. Печатающее устройство также получает фактически выданные слова.

Для изображения выбрано представление результатов кодом УПП по требованию владельца:

- Семь значащих битов кода и старший бит, дополняющий число единиц до нечётного.
- Старший бит слева, пробивки идут по строкам сверху вниз.
- 80 позиций × 12 строк, 120 восьмибитных знаков на карту.
- Код нуля 200 восьмеричное, пробела 217; незаполненные позиции содержат игнорируемый байт 000.
- Числа из двух встроенных программ читаются из десятичной машинной записи; знак и десятичная запятая сохраняются.
- Произвольные слова программы оператора сохраняются в восьмеричной записи.
- Число не разрывается между картами.

Таблица и порядок битов: [Л. А. Брухис, «Кодировки символов в БЭСМ-6»](https://www.mailcom.com/besm6/encoding_ru.html). Ссылка владельца: [Код УПП](https://ru.wikipedia.org/wiki/Код_УПП). В статье также приведено приложение 1 книги В. Я. Карпова «Алгоритмический язык фортран», 1976.

Это выбранный формат визуального представления результатов. Он не устанавливает исторический формат пробивок «Стрелы»: машинная колода ядра и её сохранение остаются словными. Геометрия, срезанный угол, строки цифр и цвет картона воспроизводятся по предоставленной фотографии; текстура строится детерминированно в SVG, без подмены пробивок фотографией.

Проверки: node web/test-upp.mjs; node web/test-wasm.mjs; ctest --test-dir build --output-on-failure. Браузер: полный пуск программы из книги с 50 и 0 мс, необязательный лимит, ручной останов бесконечной программы, фокус окна, Esc, повторное открытие, перелистывание колоды расчёта полёта и ширины 1600, 762, 375, 320.
## Просмотр введённой программы

Щелчок по стопке в считывающем устройстве открывает «Колоду программы» в том же окне просмотра. Стопка — HTML-кнопка; открытие доступно клавишами Enter и пробел. Закрытие возвращает фокус на стопку. Счёт не запускается и состояние машины не меняется.

Карты создаются из принятой машиной записи программы; редактирование поля без повторного ввода не изменяет колоду. Адрес и поля каждого слова набиваются в УПП, запись слова остаётся целиком на одной карте. Комментарии и директива START не набиваются. Под картой показаны те же записи построчно. Счётчик загрузчика и просмотр используют одну и ту же колоду. Анимация загрузки ограничена примерно двумя секундами для длинных программ.

При восстановлении снимка старый просмотр колоды очищается: исходная запись программы в снимке отсутствует. Просмотр результатов остаётся отдельным содержимым общего окна.

Проверено в Chrome: все 22 слова примера из книги на шести картах, 381 слов расчёта полёта на 96 картах; открытие клавиатурой, перелистывание, Escape и фокус, сохранение введённой колоды при редактировании поля, переход между программой и результатами, ширины 1600, 762, 375 и 320.
