## 2. Платформа

Веб-страница на HTML, CSS и JavaScript с ядром WebAssembly. Основные средства ввода: мышь, клавиатура, сенсорный экран. Язык надписей — русский; числа и адреса записываются цифрами.

Рабочие ширины: от 320 CSS-пикселей. При ширине до 720 пикселей пульт перестраивается в одну колонку; до 1240 — в две. В широком виде три основные колонки окружены вкладками памяти и носителей. Эти размеры являются решениями проекта, а не числами из UI Oracle.

Используется одна музейная палитра. Windows API, Segoe Fluent Icons, системная рамка окна и Windows type ramp не являются требованиями веб-платформы. Переносимые принципы читаемости, фокуса и клавиатурного управления применяются к HTML.

## 4. Решения проекта

### ST-001 — Музейная палитра и фотографии

**Level:** MUST. **Confidence:** HIGH. **Provenance:** PROJECT CONVENTION.

Цвета панелей и фотографии берутся из предоставленных владельцем музейных снимков. Текст управляющих вкладок располагается на отдельной непрозрачной полосе. Фотография не должна служить фоном для такого текста.

**Review test:** надпись читается без зависимости от деталей снимка; изображение не перекрывает управление.

### ST-002 — Русские обозначения

**Level:** MUST. **Confidence:** HIGH. **Provenance:** PROJECT CONVENTION.

Используются русские подписи и термины, принятые в литературе об ЭЦВМ. Названия машинных действий: «Пуск», «Останов», «Контрольный останов», «Основной такт». Пояснения к новой программе расчёта полёта могут содержать математические обозначения. Словарь хранится в `TERMINOLOGY.md` рядом с профилем.

**Review test:** один объект и одно действие имеют одинаковое название во всех местах.

### ST-003 — Разборчивый текст

**Level:** MUST. **Confidence:** HIGH. **Provenance:** PROJECT CONVENTION, перенос `UI-TYPO-002` на веб.

Обычный текст имеет размер не менее 12 CSS-пикселей, выделенный текст и подписи кнопок — не менее 14. Числовые индикаторы и машинная запись используют моноширинный шрифт. Фокус обозначается видимым контуром.

**Review test:** измерение вычисленных стилей видимого текста; проверка клавиатурного фокуса.

### ST-004 — Дополнительные панели

**Level:** MUST. **Confidence:** HIGH. **Provenance:** PROJECT CONVENTION.

Память и носители раскрываются рядом с соответствующей основной колонкой. Панель можно закрыть вкладкой, кнопкой «Закрыть» или Esc. После явного закрытия фокус возвращается на вкладку. Плюс и минус показывают закрытое и открытое состояние; HTML details сообщает это состояние вспомогательным средствам.

**Review test:** открыть и закрыть обе панели мышью и клавиатурой; убедиться, что фокус не исчезает.

## 5. Привязки общих правил

| Правило | Привязка |
|---|---|
| `UI-ERR-001`, `UX-TEXT-001`, `UX-TEXT-016` | Краткие предметные русские подписи для посетителя, изучающего работу исторической машины |
| `UX-TEXT-014` | Стандартные ограничения Oracle; дополнительных численных ограничений нет |
| `UX-TEXT-017` | `TERMINOLOGY.md` проекта |
| `UI-COLOR-005` | `web/public/style.css`, переменные музейной палитры |
| `UI-TYPO-007` | Arial/Helvetica для управления; Courier New/Consolas для чисел и машинной записи |
| `UI-ARCH-002` | Состояние машины сохраняется явно в файл; расположение временных панелей пока не сохраняется |
| `UI-EXP-003` | Многоуровневой отмены записи ячеек пока нет; состояние можно сохранить в файл |
| `UX-ERR-023` | Полная проверка разделения сообщений и диагностики ещё не проведена |

## 6. Отступления

`UI-TYPO-004`, `UI-TYPO-007` (SHOULD); `UI-TEXT-009` (MUST, отступление для исторических надписей как ограничения продукта): заводские обозначения на пульте сохраняют прописные буквы и моноширинный шрифт по историческому оформлению владельца. Обычные кнопки и пояснения используют привычные русские подписи. Пересмотр — при изменении требований к историческому оформлению. Решение: владелец проекта, требования беседы от 2026-10-09.

Windows-специфичные правила проверяются как N/A там, где зависят от Windows toolkit. Это не считается прохождением проверки. Требования доступности и контраста не отменяются.
