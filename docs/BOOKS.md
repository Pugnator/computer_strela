# Strela source books and manuals

1. **A. I. Kitov and N. A. Krinitsky, _Electronic Digital Machines and Programming_ (1959)**. Local scan: [ecm_i_prog.pdf](ecm_i_prog.pdf), chapter V, sections 27-28, printed pp. 123-141. This is the primary instruction and number-format reference. It gives the opcode table, CDD values, group operations, checksum behavior, and worked bit-mask and end-around-sum examples. The opcode table pages 128-134 are image-only in the local text layer; inspect the scans for ambiguous rows. A [separate hosted scan](https://kitov.rea.ru/uploads/files/elect2.pdf) exists.
2. **A. I. Kitov and N. A. Krinitsky, _Electronic Computing Machines_ (Электронные вычислительные машины, 1958)**. The title page of the local scan names both authors. Do not confuse it with item 1, whose Russian title is Электронные цифровые машины и программирование. [Local scan](kitov_evm.pdf) ([museum copy](https://www.computer-museum.ru/books/kitov_evm.pdf)). PDF pp. 42-49 present a complete 16-command Strela program for two linear equations, its octal listing, input card bootstrap, and numeric result. PDF pp. 35-38 describe reader, punch, tape and console, including 253 physical tape zones and a 100,000-word total. This is especially useful for end-to-end media and BCD tests. The book's printed listing includes an apparent typo in symbolic table 3 (reciprocal shown as 02); the concrete table 4 and surrounding prose say 62.
3. **A. I. Kitov, _Electronic Digital Machines_, chapter I scan**. [Separate chapter scan](https://www.computer-museum.ru/books/archiv/kitov_ecm_1.pdf), PDF pp. 15-17. Gives a Strela block diagram, card-to-RAM loading path, tape exchange, and manual single-command operation. This helps model operator behavior but supplies no per-opcode timing table.
4. **A. P. Ershov and M. R. Shura-Bura, _The Formation of Programming in the USSR_ (1976)**. [Archive text](https://ershov.iis.nsk.su/ru/foundation/index). Historical comparison table gives Strela 220 microseconds for the main tact, 2,000 operations/s average, and 30 microseconds memory access. It is a timing and variant source, not an opcode manual.
5. **Yu. Ya. Bazilevsky, "Universal Electronic Computer Strela," _Priborostroenie_ no. 3 (1957)**. The [Russian encyclopedia bibliography](https://bre.ruwiki.ru/wiki/%C2%AB%D0%A1%D1%82%D1%80%D0%B5%D0%BB%D0%B0%C2%BB_%28%D0%AD%D0%92%D0%9C%29) identifies this designer-authored article. A readable scan was not located in this search. It is a high-priority target for exact device and timing details.

The book's 253 physical zones and the programming model's 511 addressable zone numbers describe different limits or variants; they should not be silently merged. The 1958 book also records a real run whose second answer printed as 1.99999999 rather than exactly 2, giving a useful approximate result target.

The locally added _Analog Computing Machines_ (N. M. Vitenberg, 1964) concerns analog computers and has no searchable Strela references; it is not used to define this digital machine.
