# Правила работы с интерфейсом

Изменения веб-пульта выполняются по `../docs/ui/UI_PROFILE.md`. Основа — закреплённый UI Oracle 5.0.0 в `../docs/ui/oracle/`; читать правила, относящиеся к изменяемой области. Core Oracle не редактируется.

Все подписи продукта — на русском. Машинные термины берутся из литературы проекта; словарь — `../docs/ui/TERMINOLOGY.md`. Музейная палитра, фотографии и исторические обозначения задаются профилем проекта.

Текст управляющих вкладок располагается отдельно от фотографий. Размеры текста, видимый фокус, клавиатурное управление и поведение при изменении ширины проверяются в браузере. Применимость Windows-специфичных правил к вебу отражается в профиле; не заявлять полное соответствие без полного аудита.

Исходные ресурсы находятся в `public/`, статическая версия — в `dist/`. Изменения исходников включаются в статическую версию; `serve-static.mjs` содержит явный список разрешённых ресурсов.
