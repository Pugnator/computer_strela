Library subroutine: one Runge-Kutta step for y'i = fi(x, y1, ..., yn), i = 1 ... n
Source: A. I. Kitov, N. A. Krinitsky, Elektronnye tsifrovye mashiny i programmirovanie
        (1959), docs/ecm_i_prog.pdf, section 38, printed pp. 197-199, table 44.
Status: symbolic library subroutine. A2 (the right-hand sides) is problem
specific and occupies e+3 ... e+g.
Notation: ⟨N⟩ is the cell that holds N. The equation x' = 1 is added so that
x is advanced by the same scheme as the yi.

Method
  y(i,k+1) = y(i,k) + Σ K(i,j) αj,  j = 1 ... 4
  αj = (1/3) 2^(-lj),  Δxj = h 2^(-mj), obtained by order subtraction (opcode 07)
  l1=0 m1=1, l2=1 m2=1, l3=0 m3=0, l4=1 m4=0
  μ = 1 000000000000000000001100000100000010 000 000 = 4000 0006 0201 0 00

Cells (table 44), with ai = a0 + i, bi = b0 + i, ci = c0 + i, di = d0 + i,
b0 = an + 1, c0 = bn + 1
  a0 ... an   x, y1 ... yn   current values; x(k+1), y(i,k+1) after the step
  b0 ... bn   x, y1 ... yn   saved for the step
  c0 ... cn   x, y1 ... yn   arguments passed to A2
  d0 ... dn   x', y'1 ... y'n  right-hand sides computed by A2
  r           working copy of μ
