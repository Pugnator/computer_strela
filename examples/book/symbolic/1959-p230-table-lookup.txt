Subroutines that find the table cell for interpolation, y = f(x)
Source: A. I. Kitov, N. A. Krinitsky, Elektronnye tsifrovye mashiny i programmirovanie
        (1959), docs/ecm_i_prog.pdf, section 45 item 8, printed pp. 230-234.
Status: symbolic subroutines (operator P1 of the scheme P1 Φ2 Q3). Each
returns the number of the cell b+i that holds yi, as units of the first (I)
or second (II) address. A * marks a readdressed field; 7575 is the CDD
constant used to take the integer part with opcode 12.
Common check of x1 <= x < xn (Pk) and stop (Яk+1) in subroutines 2-6:
  a+1)  d+1  c+1  0000  0 03
  a+2)  a+3  a+5  0000  0 20
  a+3)  d+1  c+n  0000  0 03
  a+4)  a+5  a+6  0000  0 20
  a+5)  d+1  0000 0000  0 40
