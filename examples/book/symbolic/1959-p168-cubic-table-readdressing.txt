Table of y = x^5 + 2x + 3, cycle with readdressing
Source: A. I. Kitov, N. A. Krinitsky, Elektronnye tsifrovye mashiny i programmirovanie
        (1959), docs/ecm_i_prog.pdf, section 33 example 3, printed pp. 168-169.
Status: symbolic, depends on n.
A * marks an address changed by the readdressing operator F3(i).

Data
  b-1)  2      b)  3      b+1)  x1   ...   b+n)  xn      b+n+1)  ξ  (any number not equal to any xi)
  e+1)  1(I)   e+2)  1(I, II)   e+3)  1(III)   (the book takes them from the constant store)

Allocation printed by the book: a = 0017, b = a + 21 = 0040, c = b + n + 1 = 0041 + n.
Book error: b = a + 21 is copied from example 2. Here the data start at b - 1,
so b - 1 = 0037 and b = 0040 would overwrite commands a+20 and a+21.
A consistent choice is b = a + 23 = 0042.
