Table of y = x^5 + 2x + 3 for increasing x1 ... xn, cycle with group transfer
Source: A. I. Kitov, N. A. Krinitsky, Elektronnye tsifrovye mashiny i programmirovanie
        (1959), docs/ecm_i_prog.pdf, section 33 example 2, printed pp. 167-168.
Status: symbolic. The count n appears inside address fields, so a listing
        exists only for a chosen n. The book's allocation is
        a = 0017, b - 4 = a + 15 (so b = a + 21 = 0040), c = b + n = 0040 + n.

Data
  b-3)  xn      b-2)  2      b-1)  3      b)  0
  b+1)  x1      b+2)  x2     ...          b+n)  xn
Each pass shifts x2..xn down one cell, computes y from the old x1 (now in b)
and stores it in b+n. After n passes b+1..b+n hold y1..yn.

Program
  A1   a+1)   b-3    n+3    b-3    72
  P2   a+2)   b+1    n-1    b      45
  A3   a+3)   b      b      c+1    05
       a+4)   c+1    c+1    c+1    05
       a+5)   b      c+1    c+1    05
       a+6)   b-2    b      c+2    05

       a+10)  c+1    b-1    b+n    01
